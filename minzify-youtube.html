About search and API setup

YouTube Music has no equivalent public song-catalog search API. This page uses the official YouTube Data API v3 to find music-category videos (not necessarily every item in the YouTube Music catalogue). YouTube may block embedding for some videos.

Visitors never need an API key. Minzify uses one YouTube Data API v3 key configured by the site owner in minzify-youtube-config.js. Until the owner connects that key, visitors can open their search on YouTube Music instead. The shared key must be restricted in Google Cloud to YouTube Data API v3 and the Minzify website.

Every visitor shares the owner’s Google Cloud quota, so search may temporarily become unavailable if the daily limit is reached. Searches happen when you press Search, not on each keystroke. The YouTube Music link remains available separately.

Minzify uses YouTube's official metadata API and visible embedded video player. It does not download videos, extract soundtracks or provide free access to YouTube Music Premium. The existing Audius/Jamendo music player is separate. Minzify is not endorsed by YouTube or Google.
