How it works

🔍
1. InspectThe IPA's ZIP structure is checked in your browser; no upload needed.
🔐
2. SignA separately hosted signing service runs zsign using your certificate and profile. Certificate files are removed after signing; the password is processed temporarily in memory.
📲
3. Install legitimatelyDownload the signed app. Safari wireless installation is offered only for eligible in-house profiles; development and Ad Hoc apps may require Apple Configurator or Xcode.

Before you start

GitHub Pages can host this interface, but it cannot cryptographically sign apps by itself. Your hub administrator must connect a server. The service URL will be displayed before any credentials are uploaded.

Signing server: not configured

A valid Apple certificate alone cannot make an app install on arbitrary devices. Ad Hoc devices must be registered and permitted by the profile.

MinzSign is an independent Community Hub utility, not affiliated with Apple. Never share signing certificates with untrusted websites. Uploaded files and passwords are processed by the configured service; the browser-side inspection alone does not send files. Use only IPA files you are allowed to sign and distribute.
