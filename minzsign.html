Get apps on your phone

🍎 iPhone / iPad

No Apple Developer account is required to add a web app to your Home Screen.

  1. Open one of the web apps above in Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Choose Open as Web App if shown, then tap Add.

The app opens from an icon on your device. This is a web app, not a native IPA installation.

🤖 Android

You have two options:

  1. Tap Download APK above to obtain the existing Android app build.
  2. Or open any web app in Chrome and select Add to Home screen or Install app if offered.

Only install APKs you trust. GitHub Releases may include source files and other downloads.

Minz Apps is an independent Community Hub project. Native iOS IPA installation still requires Apple's supported signing and distribution methods; a public IPA file alone does not make an app installable. No Apple login, certificate, or private signing key is requested on this page. Apple's Home Screen instructions.
